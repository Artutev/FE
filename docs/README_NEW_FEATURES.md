## 🔍 Поиск мероприятий

### Как использовать:
1. **Перейдите** на страницу "Мероприятия"
2. **Введите** название, описание или место в поле поиска
3. **Нажмите Enter** или кнопку 🔍
4. **Смотрите результаты** — найдено X мероприятий

### Примеры:
```
Введите "футбол" → Найдёт все события про футбол
Введите "москва" → Найдёт события в Москве
Введите "лекция" → Найдёт все лекции
```

### Очистить поиск:
- Нажмите кнопку **✕** рядом с поиском
- Или перейдите на страницу "Мероприятия" заново

## 🗂 Архив прошедших мероприятий

### Что сделано
- Добавлено булево поле `is_past` в модель `Events.models.Event` для пометки прошедших событий.
- Добавлена management-команда `mark_past_events` (файл `Events/management/commands/mark_past_events.py`) — помечает события как прошедшие по дате.
- `Events/views.py` обновлён: `event_list` теперь показывает только предстоящие мероприятия; добавлен `event_archive` для просмотра архива.
- Добавлен URL-маршрут `archive/` в `Events/urls.py`.
- Добавлен шаблон архива `Events/templates/Events/eventArchive.html` и ссылка на архив в списке мероприятий.

### Как использовать
1. Примените миграции и создайте поле в БД:
```bash
python manage.py makemigrations Events
python manage.py migrate
```
2. Пометить прошедшие мероприятия (можно запускать по cron или вручную):
```bash
python manage.py mark_past_events
```
3. Перейти в интерфейсе: страница "Мероприятия" показывает только будущие события, а меню/кнопка "Архив" ведёт на страницу с прошедшими мероприятиями.

### Изменённые файлы
- `Events/models.py` — добавлено поле `is_past`
- `Events/migrations/0003_event_is_past.py` — новая миграция
- `Events/management/commands/mark_past_events.py` — новая команда управления
- `Events/views.py` — фильтрация предстоящих событий, новый `event_archive`
- `Events/urls.py` — новый маршрут `archive/`
- `Events/templates/Events/eventArchive.html` — новый шаблон архива
- `Events/templates/Events/eventList.html` — добавлена ссылка на архив, исправлена ссылка на создание события

Если нужно, могу добавить автоматический cron/task (например, `django-crontab` или Celery beat) для ежедневного запуска `mark_past_events`.

## 📅 Регистрация на события и календарь

### Что сделано
- Добавлена модель `EventRegistration` для отслеживания регистрации пользователей на события.
- Пользователи могут регистрироваться/отменять регистрацию на события через кнопку на странице события.
- На странице события отображается количество зарегистрированных человек.
- В профиле пользователя добавлен **месячный календарь** событий, на которые он зарегистрирован.
- Перечень событий в профиле с датами и временем проведения.
- Добавлены маршруты: `<event_id>/register/` и `<event_id>/unregister/`.
- Создан custom Django template filter `get_item` для работы с словарями в шаблонах.

### Как использовать
1. Перейдите на страницу события.
2. Нажмите кнопку **"Зарегистрироваться"** (требуется вход).
3. В профиле появится событие в календаре и списке регистраций.
4. Календарь автоматически показывает события текущего месяца.
5. Кнопка **"Отменить регистрацию"** удаляет событие из вашего списка.

### Изменённые файлы
- `Events/models.py` — новая модель `EventRegistration` с `unique_together` на (`user`, `event`)
- `Events/migrations/0004_eventregistration.py` — новая миграция
- `Events/views.py` — обновлён `event_detail` (информация о регистрации), добавлены `register_event` и `unregister_event`
- `Events/urls.py` — новые маршруты `register/` и `unregister/`
- `Events/templates/Events/eventDetail.html` — добавлены кнопка регистрации, счётчик зарегистрированных
- `Users/views.py` — добавлена функция `build_event_calendar()`, обновлен `profile` для передачи календаря и регистраций
- `Users/templates/Users/profile.html` — добавлены календарь и список регистраций
- `Users/templatetags/custom_filters.py` — новый фильтр `get_item`
- `Users/templatetags/__init__.py` — новый пакет
- `static/css/profile.css` — стили для календаря и списка событий

## ❓ Часто задаваемые вопросы

**Q: Где сохраняется выбор темы?**  
A: В браузере (`localStorage`). При удалении данных браузера использует системные настройки.

**Q: Работает ли поиск мероприятий без учёта регистра?**  
A: Да! "Футбол" = "ФУТБОЛ" = "футбол"

**Q: Могу ли я видеть свои предпочтения в админке?**  
A: Да! Откройте Django Admin → Users → Профиль → поле "Предпочитаемая тема"

**Q: Как добавить свой цвет в темную тему?**  
A: Отредактируй CSS переменные в `static/css/base.css` в блоке `html.dark-mode`
